# 知遇 · 个案工作实训

为社会工作专业《个案工作》课程设计的响应式网页版。当前为**可运行的教学演示**，适配电脑、iPad 和手机；反馈用于练习，不计入课程成绩。

## 启动

需要 Node.js 22 或更新版本（当前已在 Node.js 24 验证）。无第三方运行依赖、无需安装包、无需数据库服务。

```sh
cd /workspace/teacheryang_project
ADMIN_PASSWORD="请替换为自己私下设置的至少10字符密码" npm start
```

默认监听 `127.0.0.1:3000`。开发时可使用 `npm run dev`；`PORT`、`HOST`、`DATA_DIR` 可选，默认数据保存在仓库忽略目录 `.data/`。**公网演示必须开启访问口令保护；不要用于真实学生数据。**

## 已实现

- 学生学号注册与密码登录；教师及管理员由后台分配，班级权限隔离、一次性注册码、后台密码重置及首次强制改密。登录会话12小时，详见 [ACCOUNTS_SETUP.md](ACCOUNTS_SETUP.md)。
- A—E 五个案例，使用 Node.js 加密随机整数等概率抽取，每次 20%。
- 案主简介、面谈阶段、会谈目标及文字记录；可选规则演示或配置后的真实AI案主，后者使用完整本次文字上下文。
- 服务端 3 分钟最低会谈限制、5 分钟停止发送限制；到时手动结束；至少一次学生回应。
- 3—5 分钟视频选择、预览、上传、受身份控制的视频读取和范围请求播放；MP4/MOV/WebM，最大 200 MB。
- 结束文字会谈后展示教材规则复盘：配对案主与学生原话、逐项提示、章节依据、自写练习示例；上传视频后仍保留三项独立反馈，星级留空。配置模型后可另行生成有原话和章节依据的AI文字反馈及建议星级，教师可独立复核；声音与视频尚未分析。
- 至少 300 字（不计空白）的实训感受，浏览器本地草稿，完成后锁定练习；可另开练习。
- 学生只能访问自己的实训；教师可查看所授班级记录、会谈、视频和反思，填写点评，按学生及状态筛选，导出 UTF-8 BOM CSV。
- 学生与教师均可阅读10个带出处的教学知识卡和需求方五星参照；教师额外可查看五个案主的角色边界与备课指南。
- 界面区分规则脚本、教材转述、需求方量表、虚构对话及尚未接入的 AI 能力。

## 当前边界

1. **试用账号系统**：已实现账号密码、班级权限和教师重置；不接入学校统一身份认证，也不自动核实教师资格。旧昵称记录仅管理员可见，不会自动绑定新账号。首次部署需安全设置 `ADMIN_PASSWORD`，参见 [账号开通说明](ACCOUNTS_SETUP.md)。
2. **AI需配置和验证**：入口优先展示真实AI；离线规则模式按关键词选择预设回复。真实AI模式需要外部模型配置及教师连接检查，反馈需人工复核。AI建议星级仅针对文字，不代表文字与视频综合语言评分。音频及表情分析尚未实现。
3. **视频校验有限**：浏览器检查元数据时长，后端验证大小、声明时长和容器签名，尚无服务端解码、时长探测、内容审核和断点续传。只能作为演示上传。
4. **单进程演示存储**：JSON 原子替换保存元数据、本地保存视频，不支持多个进程共享数据库；没有生产级备份、删除/保留策略及存储配额；已有密码哈希和基础账号操作审计。视频加载通过授权请求读取为本地 Blob。
5. **教材接入范围有限**：已根据提供的《个案工作》（第2版）核对相关章节并整理教学转述。没有进行全文知识检索或模型训练，转述与规则仍需课程教师审阅。详见 [TEACHING.md](TEACHING.md)。
6. 用户已在 Render 打开第一版体验站。当前更新需经 Render 重新构建后生效，未从本环境核实最新公网版本；免费实例的数据可能丢失，亦未完成新云任务恢复验证。

## 正式接入需要

- 学校身份核验、统一身份系统对接（如需要）、生产级限流和权限审计。
- 对话模型与案主角色策略；在当前教学要点的基础上建立经授权、可追溯的知识检索。
- 服务端视频探测、对象存储、音频转写和多模态分析；依据教师认可的量表，输出证据与不确定性，支持人工复核。
- 数据告知同意、保留期限、删除和备份；生产数据库、HTTPS 和正式部署。

不要在聊天、源码或 Git 中填写服务密钥。待选定服务后通过安全环境设置接入。规则模式无需密钥；AI模式见 [AI_SETUP.md](AI_SETUP.md)，密钥仅在托管平台安全填写。

## 验证

```sh
npm test
```

Node 内置集成测试检查登录、权限隔离、会谈时限、持久化恢复、上传校验、未评分状态、反思字数、教师点评、CSV 和退出。时限测试仅修改隔离临时数据库的时间，不放宽应用的真实限制。

可选浏览器完整流程（需 Python `playwright`、系统 `chromium` 和 `ffmpeg`）：

```sh
python test/browser_smoke.py
python test/browser_accounts_smoke.py
python test/browser_ai_smoke.py
```

该测试使用独立临时数据和端口 3031，生成 181 秒纯色合成视频，测试桌面/手机/iPad、上传和播放、反思、教师点评及 CSV；截图写入 `/tmp/casework-smoke/`。测试视频不含真实学生信息。运行环境缺少这些工具时不影响应用启动和 Node 测试。

## 文件

- `server.js`：HTTP 服务、身份会话、实训状态流转、本地存储及导出。
- `public/`：无框架前端，响应式界面和交互。
- `teaching/`：教材章节转述、需求方案例、虚构角色边界及规则引擎。
- `TEACHING.md`：来源核对、规则局限及历史记录兼容说明。
- `ai/`：兼容 Chat Completions 的模型连接、角色提示与原话/引用校验。
- `AI_SETUP.md`：DeepSeek 安全配置与真实服务验证步骤。
- `test/`：接口、教学规则测试及可选浏览器流程。

## 体验站部署

已提供带口令保护的 Render 免费演示配置，见 [DEPLOY.md](DEPLOY.md)。部署时启用 `REQUIRE_ACCESS_CODE=1` 并通过托管平台设置至少 16 字符的 `DEMO_ACCESS_CODE`；HTTPS 使用 `COOKIE_SECURE=1`。站点口令之外还需账号密码；账号由管理员分配，仅适合非敏感演示材料。

## 启用真实 AI

详见 [AI_SETUP.md](AI_SETUP.md)。教师工作台提供模型连接检查；学生明确选择AI模式并确认资料用途后，才会发送会谈文字。连接检查、会谈和AI反馈可能消耗外部API额度。代码测试使用本地模型替身，不等同于真实DeepSeek验证。当前仍是试用账号系统和免费实例本地存储，尚不适合正式学生资料。
